01

Connexion & compte

▾

Sans le feed temps réel, aucun tick ni order flow. On branche Rithmic et on crée le compte simulé.

  • Connecter Rithmic. Sur la Console : New Connection › Rithmic puis choisis le gateway de ton trial (Rithmic Paper Trading ou Rithmic Test) et saisis username / password.
  • Accepter les Market Data Agreements. Coche les bourses CME · CBOT · NYMEX · COMEX en Non-Professional. Sans ça : pas de temps réel → tick impossible.
  • Créer le compte simulé. Configure › Accounts › Simulated › New

03

Intervalles & tick charts

▾

Le graph par défaut est en 200 ticks. On règle le tick et on recrée le sélecteur d'intervalles.

  • Mettre le graph en 200 ticks. Sur un chart, ouvre le sélecteur de Bar Size → Tick → saisis 200.
  • Recréer le sélecteur d'intervalles (menu Bar Size → Edit / Configure la liste), dans cet ordre : 1m · 5m · 10m · 15m · 20m · 30m · 45m · 1h · 2h · 6h · 1D · 1W · 1MN
  • Ajouter le 100 ms (pour l'order flow) : Bar Size → Millisecond → 100. Utile seulement pour la page Order Flow (phase 7).
    Rappel tickLes barres tick / 100 ms n'existent qu'avec Rithmic connecté. Historique tick court : laisse tourner en séance pour remplir.

06

Les 8 pages de la Console

▾

Chaque page = un onglet. Bouton « + » de la Console → choisis le type, puis agence les panneaux.

  • Home type Chart — split : en haut chart NQ 200T (applique le template resolve, DOM affiché) ; en bas la watchlist Indices + panneaux Ordres / Positions / Compte.
  • Order Flow type Chart — chart ES en 100 ms, échelle Range 200 ticks. Les études s'ajoutent en phase 7.
  • Floating type Floating — 4 fenêtres flottantes ES (voir phase 7 pour leurs études).
  • Account type Account — panneaux Comptes · Ordres · Positions & Exécutions.
  • Trade Report type Account — panneau Trade Report du compte.
  • Options type Option — deux Option Chains côte à côte.
  • Scan type Scan — deux scanners + un chart ES.
  • Optimize type Optimize — l'optimiseur de stratégie.
07

Études order flow & floating

▾

Les indicateurs spécifiques de chaque page. Ajoute-les via Study › Add Study sur le bon chart.

  • Order Flow → Order Heatmap. Sur le chart ES 100 ms : ajoute Order Heatmap (maxHistory 1000).
  • Order Flow → Bid Trades. Ajoute Bid Trades (bulles) : aggPeriod 10, taille max bulle 60, opacité ~0.8.
  • Floating #1 — ES 15m : Volume (bas) + Harmonic.
  • Floating #2 — ES 15m : Volume + VMA + Hurst Cycles.
  • Floating #3 — ES 15m : Volume + Elliott Wave.
  • Floating #4 — ES 1m : VIMPRINT footprint mode bid/ask, échelle Range 30 ticks.
08

Ordres, sorties & barres d'outils

▾

Les réglages de trading et l'interface, pour un rendu 100 % identique.

  • Stratégies de sortie (brackets). Configure › Exit Strategies
    Bracket 1100 % position
    Bracket 2target +20 ticks
    Bracket 333% · 33%@+20 · 34%@+30
  • Presets d'ordres. Type LMT par défaut, offsets 10 ticks (limit / stop / trail) pour les futures, trigger hors-séance activé.
  • Panneau de trading. Deux vues : Position (quantité, Buy/Sell Market/Ask/Bid, Break-Even, Reverse, P/L) et Order (type + P/L).
  • Barres d'outils. Configure › Toolbars → TOP active (outils + studies + DOM + order book + trade panel), LEFT active (dessin), et TOP2 · BOTTOM · RIGHT désactivées.
09

Sauvegarde & vérif

▾

On fige tout pour ne rien reperdre.

  • Assigner ton compte. Sur chaque chart : clic droit → Account → ton compte Rithmic (le template pointait vers un compte de test étranger).
  • Vérifier le tick. Ouvre la page Home en séance → le 200T doit se remplir tick par tick.
  • Sauvegarder la workspace. Console › Save Workspace — puis fais un backup (exporte le dossier de la workspace).
