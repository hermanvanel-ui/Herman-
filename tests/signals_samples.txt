# Sample Trading Signals for Testing
# Various formats that the parser should handle

# Format 1: Standard format
BUY XAUUSD @ 2054 SL 2046 TP 2070

# Format 2: Lowercase
sell eurusd now SL:1.0920 TP:1.0880

# Format 3: Range entry
XAUUSD BUY 2050-2052 SL 2044 TP1 2060 TP2 2072

# Format 4: No @ sign
BUY GBPUSD 1.2650 SL 1.2620 TP 1.2700

# Format 5: Long/Short notation
LONG GOLD at 2055.5 stop loss 2047 take profit 2068

# Format 6: Symbol shortcuts
GU BUY @ 1.2680 SL: 1.2650 TP: 1.2730

# Format 7: Multiple TPs
SELL EURUSD @ 1.0900 SL 1.0930 TP1 1.0870 TP2 1.0850 TP3 1.0820

# Format 8: No entry price (market order)
BUY BTCUSD SL 42000 TP 48000

# Format 9: Spaces and formatting variations
SELL   XAUUSD    @   2060   SL:  2070   TP:  2040

# Format 10: With additional text
🔥 SIGNAL ALERT 🔥
BUY EURUSD @ 1.0850
SL: 1.0820
TP: 1.0900
Good luck!

# Format 11: Close signal
CLOSE XAUUSD

# Format 12: Partial close
Close 50% EURUSD

# Format 13: Move SL to BE
Move SL to BE GBPUSD

# Format 14: Move SL to breakeven (variation)
XAUUSD move stop loss to entry

# Format 15: Exit signal
EXIT GOLD

# Format 16: Book profit
Book profit on EURUSD

# Format 17: With emoji and extra info
📈 BUY SIGNAL
Pair: XAUUSD
Entry: 2055
Stop Loss: 2045
Take Profit: 2070
Risk/Reward: 1:1.5

# Format 18: Slash in pair name
BUY GBP/USD @ 1.2700 SL 1.2670 TP 1.2750

# Format 19: Crypto pairs
BUY BTCUSD @ 45000 SL 43500 TP 48000

# Format 20: No clear separators
XAUUSD SELL 2060 SL 2070 TP 2040
